Genome coverage analysis

To assess the genome coverage we use mosdepth and plot the cumulative coverage distribution.

Run mosdepth

# Run mosdepth long read samples
mosdepth --threads 4 --fast-mode D0 ./scdnalong/results/D0.dedup.sorted.bam&
mosdepth --threads 4 --fast-mode Q1 ./scdnalong/results/Q1.dedup.sorted.bam&
mosdepth --threads 4 --fast-mode Q2 ./scdnalong/results/Q2.dedup.sorted.bam&
mosdepth --threads 4 --fast-mode Q3 ./scdnalong/results/Q3.dedup.sorted.bam&

# Run mosdepth short read sample
mosdepth --threads 4 --fast-mode Q3_short ./scdnalong/results_short/Q3_short.dedup.sorted.bam&
